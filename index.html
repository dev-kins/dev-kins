Personal Project

Naic-OpenGov

Naic OpenGov is a full-stack GovTech web application built for local government units to improve project monitoring, budget oversight, procurement tracking, public transparency, and citizen engagement. Developed with Laravel, MySQL, Blade, Bootstrap, interactive maps, analytics dashboards, role-based access control, audit logs, reporting tools, and a public transparency portal, the system centralizes operational and financial data into one platform for administrators, staff, and citizens. It was designed as a realistic municipal governance solution that supports accountability, decision-making, and public access to local government information.

Web App Civic Tech Frontend System Design
Problem It Solved

Local government operations and public transparency often live across scattered records, making it harder to monitor projects, budgets, and citizen-facing information from one place.

Key Features
  • Governance dashboard and project monitoring views
  • Budget oversight and transparency-focused pages
  • Notification and role-based access flows
  • Public portal for citizen-facing access to information
